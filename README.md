# Universal PiP — 任意视频一键画中画

给网页上任意视频添加一个浮动的画中画按钮，点击即可切换到小窗播放。
适用于 Chromium 内核浏览器。

## 特点

  1. 优先调用**系统级原生画中画**（真悬浮置顶窗口，切标签也不消失）；
  2. 原生 API 被网站拦截时，自动用 `captureStream()` 在**页内开固定小窗**兜底（支持拖动 / 最小化 / 关闭，并同步源视频的播放、暂停、音量）。
- **跟随鼠标自动隐藏**：像原生播放条一样，鼠标移入视频才显示按钮，停顿约 2.6 秒、移出视频区域或全屏空闲时**平滑淡出**。
- **适配动态网页**：用 `MutationObserver` 自动识别 SPA 中动态加载的视频；`all_frames` 也支持 iframe 内嵌视频。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | Manifest V3 清单，声明 content script 覆盖全部站点 |
| `content.js` | 核心逻辑：注入按钮、系统级 PiP + 页内小窗兜底、自动隐藏 |
| `style.css` | 按钮与小窗的样式 |
| `dist/` | 构建产物：`universal-pip.crx`（拖拽安装）、`universal-pip-source.zip`（加载已解压） |

## 安装（二选一）

**方法 A · 拖拽 .crx 安装（推荐）**
1. 从仓库 `dist/` 目录下载 `universal-pip.crx`；
2. 打开扩展页：`chrome://extensions`（Helium 为 `helium://extensions`）；
3. 开启右上角 **「开发者模式」**；
4. 把 `universal-pip.crx` **直接拖进页面**，松开即可安装；出现外部扩展警告时点「保留」。

**方法 B · 加载已解压源码**
1. 下载并解压 `dist/universal-pip-source.zip`，得到一个文件夹；
2. 扩展页开启开发者模式后点 **「加载已解压的扩展程序」**，选择该文件夹。

> 安装后：打开任意含视频的网页，鼠标移到视频顶部，点居中的 ⚪ 按钮即可进入小窗。





> 更新方法：替换源码文件后，在扩展页点该扩展的 **刷新（↻）** 按钮即可生效。

## 使用

- 系统级 PiP：点击后浏览器弹出系统悬浮小窗（B 站、YouTube 常规站点）。
- 页内小窗：若原生 PiP 被拦截，右下角弹出固定小窗——按住标题栏可拖动，`—` 最小化，`✕` 关闭，播放/暂停/音量随源视频同步。

## 自定义

- 调整按钮自动隐藏的等待时长：改 `content.js` 中 `2600`（毫秒）这个值。
- 调整按钮尺寸 / 位置：改 `content.js` 中 `30px` 与居中公式，或改 `style.css`。
